### Featured Projects

<table>

<td width="100%">

**[TicketPulse](https://github.com/iammjdev/ticketpulse-backend)** — high-throughput distributed ticketing engine

Enterprise-grade backend built to survive flash-sale traffic spikes with a **zero-overselling guarantee**, using atomic Redis Lua inventory locks, real-time virtual queueing over Redis ZSETs + SSE, and eventual-consistency order persistence through Kafka (KRaft) and PostgreSQL. Benchmarked at **5,800+ RPS** with k6. Paired with a [Next.js 15 / React 19 frontend](https://github.com/iammjdev/ticketpulse-frontend) that consumes the SSE stream for live queue-rank updates via Zustand.

**[LuxAPI](https://github.com/Nova-Co/LuxAPI)** — Kotlin developer API for Cobblemon

Wraps Cobblemon's internals — storage, spawning, battles, dialogue, NPCs — behind a small, ergonomic, well-documented layer, so third-party mod developers can build features on Fabric and NeoForge without reverse-engineering Cobblemon's source.
